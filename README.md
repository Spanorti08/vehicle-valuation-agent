# Vehicle Valuation Agent

一个人工参与的车辆市场法评估工作流助手。

## 项目目标

辅助资产评估人员核对车辆资料、整理市场可比案例、计算修正价格，并生成车辆评估技术说明初稿。

本项目只使用公开资料和合成数据，不代替资产评估人员作出专业判断或正式评估结论。

## 输入

1. 甲方提供的车辆明细
2. 机动车行驶证图片
3. 评估基准日
4. 人工填写的现场车况
5. 三个或以上二手车市场可比案例
6. 评估人员确认的调整参数

## 工作流程

1. 读取甲方车辆明细
2. 识别并核对行驶证信息
3. 整理三个市场案例
4. 比较上牌时间、里程和车况
5. 由评估人员确认调整参数
6. 计算修正价格和最终评估值
7. 将结果写入Excel
8. 生成车辆评估技术说明初稿
9. 输出人工复核问题

## 输出

- 完成计算的车辆评估Excel
- 车辆评估技术说明Word初稿
- 数据差异和人工复核清单

## 人工决策边界

系统不会自动决定：

- 车辆真实状况
- 市场案例是否最终可用
- 调整参数是否合理
- 最终评估结论是否可以采用
