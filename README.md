# Vehicle Valuation Agent

一个人工参与的车辆市场法评估工作流助手。

## 项目目标

辅助资产评估人员核对车辆资料、整理市场可比案例、计算修正价格，并生成车辆评估技术说明初稿。

本项目只使用公开资料和合成数据，不代替资产评估人员作出专业判断或正式评估结论。

## 输入

1. 甲方提供的车辆评估明细Excel
2. 机动车行驶证图片
3. 评估基准日
4. 现场核查人员选择的车辆状况等级
5. 可选的现场补充说明

## 工作流程

1. 从Excel读取待评车辆信息
2. 从行驶证识别车辆信息
3. 核对Excel与行驶证中的车牌、型号和日期
4. 根据待评车辆信息自动搜索二手车市场案例
5. 对候选车辆进行相似度排序，默认推荐至少三个案例
6. 用户可以添加、删除或替换市场案例
7. 系统通过确定性规则和AI生成比较指数建议及理由
8. 用户修改并确认市场案例和比较指数
9. 按照市场法公式计算各案例的修正价格和最终评估值
10. 将结果写入车辆评估Excel
11. 生成车辆评估技术说明Word初稿
12. 输出数据差异及人工复核清单

## 人工确认边界

以下内容必须由评估人员确认：

- 待评车辆的现场状况
- 推荐的市场案例是否可比
- 比较指数是否合理
- 最终计算结果是否可以采用

AI生成的市场案例排序和比较指数仅作为建议，不构成正式评估结论。
