# 工作流离线评测

## 目的

这套评测回答三个可以在简历和面试中复现的问题：

1. 常见 OCR 字段错误能否在有可信参考资料时自动校准？
2. LangGraph 市场搜索能否正确扩城、重试、自动选择并在无解时暂停？
3. RAG 检索策略在保留测试问题上的表现如何？

运行：

```bash
conda activate vehicle-valuation-agent
python scripts/evaluate_workflow.py
```

结果写入 `data/evaluation/workflow_evaluation_results.json`。脚本本身不访问真实二手车网站或 Ollama，因此字段和搜索基准可以离线重复运行。

## 资料校准基准

共 8 个合成场景：完全一致；品牌后缀和法定型号标点误识别；车牌字母数字混淆；VIN 字母数字混淆；置信度较低但与 Excel 一致；发动机号缺失；车牌实质冲突；低置信度注册日期冲突。

| 指标 | 结果 |
|---|---:|
| 可自动处理场景关键字段正确率 | 100% |
| 标记为可自动修复的场景成功率 | 100%（3/3） |
| 正常/异常分流准确率 | 100%（8/8） |
| 当前场景组合自动通过率 | 62.5%（5/8） |

这个基准直接调用 `calibrate_license_fields`、`DrivingLicenseData` 和 `run_license_subject_checks`。它没有读取行驶证图片，所以不能称为 RapidOCR 原始识别准确率。

## 市场 Agent 基准

共 5 个离线场景：首批直接得到 3 个案例；扩展城市后成功；有限重试后成功；资源耗尽后仍不足；全部案例低于 60 分相似度硬门槛。

| 指标 | 结果 |
|---|---:|
| 可解场景搜索成功率 | 100%（3/3） |
| 可解场景自动 Top 3 就绪率 | 100%（3/3） |
| 成功场景平均搜索轮数 | 1.67 |
| 60 分以下案例拦截率 | 100%（3/3） |
| 成功或暂停状态符合预期 | 100%（5/5） |

该基准使用合成 `MarketListing` 和离线 SearchBackend，测试的是 LangGraph 分支、状态和业务门槛，不是网站实时抓取成功率。

## RAG 基准

工作流结果文件会读取 `data/rag/evaluation_results.json` 的固定结果。15 个问题中，10 个用于选择 RRF 权重，5 个用于独立测试：

| Retriever | Hit@3 | Mean Recall@3 | MRR@3 |
|---|---:|---:|---:|
| BM25 | 60.0% | 60.0% | 0.600 |
| FAISS | 100.0% | 100.0% | 0.867 |
| Weighted Hybrid RRF | 80.0% | 80.0% | 0.700 |

## 结果边界

- OCR 字段错误是人工构造的代表性样本，不能外推所有照片质量；
- 62.5% 自动通过率受正常/异常样本配比影响，不是生产统计；
- 市场 Agent 使用离线后端，不能证明真实网站稳定；
- RAG 测试集只有 5 个保留问题，适合作为基线，不足以证明通用能力；
- 评测输出保留逐场景记录，任何汇总数字都可以追溯到具体输入和决策。

## 增加新场景

- 资料错误：在 `_license_scenarios()` 增加输入、预期字段和预期人工分流；
- 搜索分支：在 `evaluate_market_agent()` 增加离线后端响应和预期状态；
- RAG 问题：新增标注问题时必须重新划分 tuning/test，不能反复用现有 5 题调参。
